# 図解取扱説明書の作り方

完成品: [output/pdf/hunet_vids_図解取扱説明書.pdf](../../output/pdf/hunet_vids_図解取扱説明書.pdf)（A4・30 ページ。アプリからは `/guide.pdf` で開けます）

```bash
npm run manual
```

1 つのコマンドで、次の 3 段階を実行します。

1. `npm run build` で本番ビルドを作ります。
2. `docs/manual/capture.mjs` が、本番と同じヘッダーで配信したアプリを Chrome で操作し、説明に使う 23 画面を撮影します。各ボタンや入力欄の位置も `images/bounds.json` に記録します。
   - 実在の API キーは使いません。ほとんどの画面は体験モード（AI の代わりに仮の素材を作る）で撮影し、エラー画面だけは説明用のダミーキーを使い、Google への通信はすべて手元で偽の応答を返します。
   - 録画画面はブラウザの試験用カメラ映像を使います。
3. `docs/manual/build.mjs` が、画面写真に番号の吹き出しを重ね、図（SVG）と説明文を組み合わせた HTML を作り、Chrome で PDF に印刷します。しおり（目次）とリンクも付きます。どのページも A4 の範囲に収まっているかを検査し、はみ出すと失敗します。

最後に `scripts/copy-guide.mjs` が PDF を `dist/guide.pdf` に写し、アプリの「使い方（PDF）」から開けるようにします（通常の `npm run build` でも写します）。

## 直すとき

- 説明文・ページ構成は `build.mjs` の `pages` にあります。吹き出しは `fig('画面名', [['要素', 番号, 置き場所]])` で指定します。置き場所は `tl`（左上）・`l`（左）・`r`（右）・`tr`（右上）・`c`（中央）です。
- 撮影する画面と要素は `capture.mjs` にあります。画面の文言を変えたら、ここの指定も合わせてください。
- 画面写真は `images/` に、途中の HTML は `manual.html`（git に入れない）に出力されます。
- 生成した PDF は、ページを画像にして目で確認してください（例: `uv run --with pymupdf` で各ページを PNG に書き出す）。
