## 手動での確認（体験モード、ブラウザ操作）

2026-10-13 に、ローカルと公開サイトで確認しました。

- 指示文→絵コンテ→ナレーション・背景・BGM の自動生成→再生→MP4 書き出し。書き出した動画は 1920×1080・音声あり、見出しと字幕が映像に入る。
- 人物動画（アバター風）、9:16 への切り替え、スマートフォン幅の表示。
- 保存ファイルの往復（素材のバイト一致）、壊れたファイルの拒否、編集直後の離脱でも保存されること、同名シーンの一括生成（2 件同時＋1 件待機）。
- 繰り返し背景動画の書き出し（繰り返し部分のコマが冒頭と一致し、止まらない）。
- 公開サイトの CSP の下で、Gemini API へは届き（無効なキーに対する 400 応答を受信）、他サイトへの通信は遮断される。

未確認の主な点：

- 各モデル（台本・TTS・画像・Omni・Lyria）が実際にこの形で応答するか
