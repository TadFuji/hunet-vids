# 表示・再生・延長の限定修正（ローカルのみ）

本人が承認した3点のみを変更した。アプリ版は2026-10-16.13。本番公開はこの修正版に対する明示確認が必要として自動承認レビューで拒否されているため、Vercelへの公開・昇格・alias変更は一切行っていない。公開中は5cab7fbのまま。

## 変更

1. 履歴の「表示」は、版を選択して中央プレビューへscrollし、動画プレーヤーへfocusする。再生は開始しない。
2. 履歴の三角印をtype=buttonの再生操作にし、タイムラインの「再生」と共に選択後にvideo.play()を呼ぶ。失敗時は固定の再生案内を専用欄へ表示し、生成エラー・確認中ジョブを上書きしない。別版選択やリセット後の遅延rejectは世代番号と選択IDで無視する。
3. UI/coreのviewed必須条件だけを除去した。完成版への採用は今までどおり実尺・画角などの検査通過後に行う。確認中のbusy/pending、正常性/尺/画角不一致の保持、キー必須、40秒上限、明示的な分岐は維持する。表示/再生だけでは延長元を変えない。
