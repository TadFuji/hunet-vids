# my-vids

Google Vids のように、指示文から動画を作るウェブアプリです。台本（絵コンテ）、ナレーション、背景の画像・動画、BGM を Gemini で生成し、ブラウザの中で編集して MP4 に書き出します。**書き出した動画に透かしは入りません。**

各自が自分の Gemini API キーを入れて使います。キーはそのブラウザの中だけに保存され、Google の API 以外には送られません。作った動画や素材も、そのブラウザの中（IndexedDB という保存領域）に保存されます。

## できること

- 指示文（と参考資料）から、シーンごとの絵コンテを自動作成（長さ・画面の形・テーマ・声・言語を指定）
- ナレーションの生成（30 種類の声、話し方の指示、AI による文章の書き換え）
- 背景の生成：画像（Nano Banana）、音声つき動画（Gemini Omni、4〜10 秒）、画像を動かす、指示での画像編集
- 人物がセリフを話す動画（アバター風）
- BGM の生成（Lyria、30 秒ループ／2〜3 分の曲）。ナレーション中は自動で音量を下げます
- テキスト（見出し・本文・ラベル・テロップ）、登場アニメーション、シーンの切り替え効果、背景のズーム・パン
- ナレーションからの自動字幕（位置・色・帯を変更可能、.srt で保存可能）
- カメラ・画面・画面＋カメラの録画（原稿を表示するプロンプターつき）
- 画像・動画・音声のアップロード
- タイムライン（シーンの長さをドラッグで変更）、シーンの並べ替え・複製、元に戻す／やり直す
- MP4 書き出し（1080p／720p、24・30・60fps）
- プロジェクトを素材ごと 1 つのファイル（.myvids）に保存・読み込み（一覧画面の「ファイルに保存」「ファイルから開く」）
- API キーなしで操作を試せる「体験モード」（AI の代わりに仮の素材を作ります。費用はかかりません）

Google Vids との比較と調査結果は [docs/research.md](docs/research.md) にあります。

## 費用の目安（2026-10-13 時点の Google の公開価格）

- 台本・ナレーション：Gemini API の無料枠で使えます
- 画像：1 枚 約 $0.03
- 動画：720p で 1 秒 約 $0.10（8 秒で約 $0.80）
- BGM：30 秒 $0.04、1 曲 $0.08

画像・動画・BGM には、Google AI Studio で課金（Billing）の設定が必要です。実際の請求額は AI Studio で確認してください。

## 使い方（自分のパソコンで動かす）

ターミナルで次を実行します。

```bash
cd /Volumes/ROCKET_XTRM/coding/my-vids
```

```bash
npm run dev -- --port 5178
```

ブラウザ（Chrome か Edge）で http://localhost:5178 を開きます。終了するときは、ターミナルで `Ctrl + C` を押します。

1. 最初の画面で Gemini API キーを貼り付けて「確認して保存」を押します（キーは https://aistudio.google.com/apikey で作れます）。
2. 「どんな動画を作りますか？」に内容を書いて「AI で絵コンテを作成」を押します。
3. 編集画面で、シーン・テキスト・音声・素材・BGM を調整します。スペースキーで再生／停止できます。
4. 右上の「書き出し」から MP4 を保存します。

## 友人に使ってもらうには

このアプリはサーバーを必要としない静的なウェブサイトなので、Vercel や Cloudflare Pages などに置けば、URL を共有するだけで使ってもらえます。公開する場合は、事前に Claude に依頼してください（公開には藤川さんの承認が必要です）。友人はそれぞれ自分の API キーを入れて使います。

## 注意

- 動作確認は Chrome で行っています。Safari では MP4 の書き出しができない場合があります。
- ブラウザのデータ（サイトデータ）を消すと、保存した動画プロジェクトと素材も消えます。大事なプロジェクトは「ファイルに保存」でバックアップしてください。
