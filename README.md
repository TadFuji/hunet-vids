# Omni Continue Studio

文章または自分で選んだ動画から続きをつくる、日本語のWebアプリです。動画生成には **Gemini Omni 1.1 Flash**、ナレーション・対話音声生成には **Gemini 3.8 Flash TTS / Flash-Lite TTS**、BGM・ボーカル音楽生成には **Lyria 3.5 / Lyria 3 Clip** を使用する構成です。画角・動画解像度と **3〜10秒** の長さを選び、最大40秒まで延長しながら各版を残します。完成した動画には、自由度の高いナレーション音声やAI作曲したBGM・楽曲を好きな開始秒数・音量バランスで重ねることができます。

**利用者からローカル版で実生成成功の報告を受けています。エージェントによる実API生成・キー操作・課金検証はしていません。** 公開アプリはご本人のキーによる実API利用専用です。オフラインの開発用モック・合成動画は非公開のtest配下だけに保持しています。

## 公開版

公開URL：
- **https://hunet-vids.vercel.app/**
- **https://unko-omni.vercel.app/**

Vercel公開版は、文章から3〜10秒の生成・延長に加え、動画取込、末尾抽出、接続、「やさしい音声づくり」統合のナレーション生成、および **Lyria 3.5** による音楽・BGM生成と動画音声ミックスに対応しています。動画の加工と音声の合成は利用者のブラウザ内（ffmpeg.wasm）で行い、Vercelや別の処理サーバーへ動画・音声を送りません。初回取込は60秒・50MiB・720p以下、継続・合成は90秒・100MiB以下です。各利用者が自分のキーを入力します。

[公開構成と手順](docs/publishing.md)、[対応範囲と検証](docs/browser-processing.md)を参照してください。

## 起動する

Finderでこのフォルダの **「起動.command」** をダブルクリックしてください。起動ウィンドウが終了しても、アプリは独立したプロセスとして動き続けます。Node.js 22以降が必要です。動画の取り込み・接続には、このMacにある `/opt/homebrew/bin/ffmpeg` と `ffprobe` を使います。npmパッケージの追加はありません。

ターミナルから起動する場合は、次を実行します。

```sh
cd omni-continue-studio
./起動.command
```

ブラウザで **http://127.0.0.1:4317/** を開きます。このMacの中だけで動き、外部には公開されません。終了するときは **「停止.command」** をダブルクリックします。ターミナルでは同じフォルダで `./停止.command` を実行します。状態確認は `npm run status` です。

Mac再起動後は、自動起動せず停止しています。再び「起動.command」を開いてください。ログイン項目やlaunch agentは追加していません。起動済みなら同じプロセスを使い、二重起動しません。停止処理は、この作業先で起動したプロセスの識別情報が一致した場合だけ行います。他のプロセスは停止しません。

もし `npm start` で手動起動したものが残っている場合は、そのターミナルでControl+Cを押してから「起動.command」を開いてください。管理外の起動を、独立プロセスで起動済みとは扱いません。開発用の `npm start` は手動の前面起動であり、ターミナルを閉じると停止します。

起動状態と起動診断ログは `.runtime/` にだけ保存します。プロセスID・開始時刻・作業先の照合値と起動メッセージのみで、APIキー・プロンプト・動画は保存しません。HTTPアクセスログも記録しません。

## ご本人のAPIキーで使う

1. 「Gemini API キー」にご本人がキーを入力します。入力中はこのタブのメモリだけで保持し、入力だけではAPIへ通信しません。入力欄を空にするか「キーをメモリから消去」で直ちに未入力扱いになります。空白だけの入力も未入力です。
2. 右上で画角・動画の解像度、入力欄の上で長さ（3〜10秒、既定10秒）を選び、最初のシーンを入力して生成ボタンを押します。料金確認のチェックボックスはありません。料金・保存の説明は画面下にあります。この操作でGoogleへ有料の生成リクエストを送ります。入力済みでもキーの有効性は保証されず、認証エラーはGoogleの応答で表示します。
3. 動画情報の確認を通った完成版は、再生終了を待たずに、続きの内容と追加する長さ（3〜10秒）を選んで延長できます。残りの予定尺を超える値は選べず、合計40秒（または残り3秒未満）で止まります。履歴の「表示」は中央プレビューへ移動し、三角ボタンとタイムラインの「再生」は実際に再生します。過去の版から別展開を作る場合は分岐操作を明示的に選びます。

## ナレーション・音声スタジオ（やさしい音声づくり統合）

プレビュー下の「ナレーション・音声スタジオ」では、**Gemini 3.8 Flash TTS** / **Flash-Lite TTS** を使って動画用のナレーションや対話音声を作成し、選択中の動画に合成できます。

- **1人読み上げ・2人の会話**：1人でのナレーションに加え、2人の話し手による自然なかけあい（`|うん|` などの相づち対応）を生成できます。
- **声と話し方の自由な指定**：30種類のプリセット音声、Googleの拡張音声ライブラリ（約2,000種類、検索・お気に入り対応）、21種類の話し方・雰囲気、3段階の速度、文中の `【話し方:落ち着いて】` による途中切り替えに対応しています。
- **全36種類の表現タグ**：`<short pause>`（ひと呼吸）、`<long pause>`（長めの間）、`<breath>`（息を吸う）、`<laugh>`（笑う）、`<sigh>`（ため息）、`<whispers>`（ささやく）など12カテゴリ・36種類の表現タグをワンクリックで挿入できます。
- **声をつくる（Voice Design）・声を複製する（Voice Replication）**：言葉の説明から新しい声を作る機能と、10〜30秒のサンプル音声＋同意音声からブラウザ内で24kHzモノラルWAVへ自動変換して声を複製する機能を備えています。
- **動画の元音声との音量調整つきミックス・復元**：開始位置（秒）、元の動画の音量（0%〜200%）、ナレーションの音量（10%〜200%）を指定して動画の映像を無劣化（`-c:v copy`）のまま音声ミックスします。追加の重ね録りや「元の動画音声に戻す」による復元も可能です。また、ナレーション入り動画をさらに延長する際は、Google側へ送る末尾10秒には自動的にナレーション合成前のクリーンな動画（`cleanBlob`）を使い、ローカルの前半結合ではナレーション入り動画を維持します。

## 音楽・BGMスタジオ（Lyria 3.5 フル統合）

ナレーションスタジオの下にある「音楽・BGMスタジオ（Lyria 3.5）」では、Googleの最新音楽生成モデル **Lyria 3.5**（`lyria-3.5`：44.1kHzステレオ、最大180秒、構造・歌詞指定対応）および **Lyria 3 Clip**（`lyria-3-clip-preview`：約30秒の短尺クリップ試作）をフル活用して映像用のサウンドトラックや歌入り楽曲を生成できます。

- **BGM・インスト（歌なし背景音楽）とボーカル曲（歌入り）の切り替え**：映像の背景音楽に最適なインストゥルメンタル指定（ナレーションが聞き取りやすいよう中音域をすっきりさせるバランス設定つき）と、日本語・英語の歌詞を歌い上げるボーカル曲（女性・男性・男女デュエット・ウィスパー・コーラス・メロディックラップの6種）を選べます。
- **細かな音楽ディレクション指定**：17種類のジャンル・音楽スタイル、12種類の雰囲気・ムード、16種類の楽器チップ（複数選択可）、テンポ感とBPM（40〜220）、12種類の調性（キー・Major/Minor）、目標の長さ（10〜180秒、または「動画に合わせる」ボタンで自動同期）、エンディングの終わり方（余韻フェード・ピタッと終える・ループ向き）を細かく指定できます。
- **歌詞・セクション構成タグ挿入と生成歌詞の表示**：`[Intro]`、`[Verse 1]`、`[Pre-Chorus]`、`[Chorus]`、`[Instrumental Break]`、`[Bridge]`、`[Drop]`、`[Final Chorus]`、`[Outro]` などの構成タグをワンクリックで挿入でき、Lyria側が出力した歌詞・構成メモも画面で確認できます。
- **映像の画面や画像から作曲（マルチモーダル音楽生成）**：「表示中の動画の現在の画面を取り込む」または手持ちの画像（JPEG/PNG/WebP）を選ぶことで、映像の色合いや情景をLyria 3.5に直接読み取らせて音楽を作曲できます。
- **ナレーションとの重ね合わせ・動画への合成**：生成した音楽（MP3/WAV）は単体でダウンロードできるほか、ブラウザ内で44.1kHzステレオWAVへ変換し、動画の元音声やナレーション音声の上に好きな音量バランス（例：ナレーション100%＋BGM 45%）で重ねて合成できます。

キー未入力時の生成・延長ボタンは入力が必要だと分かる外観にし、クリックまたはキーボードで実行すると「Gemini の API キーを入力してください」とアラートを表示します。API要求は送信しません。生成中・結果確認待ち・40秒上限のロックは維持します。APIから同じ結果を再取得する操作もキーが必要です。すでに受信済みの動画の再生・保存・ローカル再計測と診断保存は、キーを消しても利用できます。

- キーはこのタブのメモリだけに保持します。コード、設定ファイル、ログ、URL、LocalStorage、SessionStorageには保存しません。
- ブラウザから `https://generativelanguage.googleapis.com` へ `x-goog-api-key` ヘッダーで直接送信します。このアプリのサーバーへキーを渡しません。第三者のSDK、フォント、アクセス解析も読み込みません。
- 送信中のキー変更は止めています。結果確認待ちでは、ジョブを保ったままキーを消去・再入力できます。キーがなければAPI取得は止まり、元の結果確認と新規POSTのロックは残ります。
- 作品とプロンプトもタブのメモリだけにあります。必要な動画は必ずダウンロードしてください。キーの消去だけでは作品・診断を消去しません。
- 延長にはGoogle側の履歴が必要なため `store: true` で送ります。Google側にはプロンプト・生成物・生成IDが保存され、Googleのデータ保持条件が適用されます。キーの消去やアプリ初期化はGoogle側の履歴削除ではありません。

## 自分の動画から始める

「最初の動画」で「動画を取り込む」を選び、MP4・MOV・WebMを選択します。横16:9・縦9:16、200MiB以下・20分以下に対応します。対応する画角に近い非標準サイズは、近い360p／720p／1080p／4Kへ正規化します。取り込み後に表示する設定は末尾処理と延長出力の設定です。文章生成の既定360pを、元の720p動画へ勝手に適用しません。

選択したファイルだけを、このMac内のloopbackサーバーへ渡します。ffmpeg処理の間だけOS一時領域へコピーし、成功・失敗・切断時に消去します。元ファイルは変更しません。ブラウザは元動画と切り出した末尾をメモリに保持し、元動画と送信前の末尾を個別保存できます。切り出しと接続時はH.264・24fps／AACへ再エンコードし、元の音声を勝手に無音化しません。音声がない区間の接続には無音を補います。画質・音質やつながりの完全維持は保証しません。

**ファイル選択・ローカル準備だけではGoogleへ送信しません。** 元動画を再生し、続きを入力して延長ボタンを押すと、本人のキーを使って末尾10秒以下のMP4だけをGoogle Filesへ送り、ACTIVEを確認してから有料Interactions生成を1回送ります。元の前半はGoogleへ送りません。Filesは最大48時間保持され、生成履歴はstore:trueでGoogle側の保持条件が適用されます。アップロード用CORSと実生成は未検証です。

追加時間は3〜10秒から選べます。元動画が60秒なら、前半約50秒を保持し、末尾10秒を約20秒へ延長したモデル結果とローカル接続して全体約70秒を保存します。**この展開の予定尺は合計40秒まで**で、元動画の前半を含む保存全体とは別に表示します。通常はモデル結果のprevious_interaction_idで延長し、同じ前半へ接続します。最低3秒の生成でモデル部分が40秒を超える場合は、現在の完成版（ナレーション合成前のクリーンな動画）から末尾10秒以下を切り出してGoogleへ送り直し、残りをローカルで接続します。40秒の予定上限はこの送り直しでもリセットしません。元の60／70秒全体をGoogleへ送ることはありません。元動画の情報と各完成版は保ち、画面の元動画末尾の保存リンクは最初に取り込んだ素材を指します。

持ち込み動画への新しいセリフ追加は非対応です。アプリはアップロード由来の延長へ新たな話し言葉を加えない指示を付けます。EEA・スイス・英国では持ち込み動画の延長を利用できません。モデルは末尾の一部フレームを調整します。自然な接続、セリフ・元音声の完全維持を保証しません。

モデル結果の尺や素材・親IDの照合に失敗した場合は完成扱いにしません。ローカル接続だけが失敗した場合も元動画・モデル出力・IDを保持し、「保存済み動画を再計測・仕上げ」で受信済みデータから接続だけを再試行できます。有料POSTは再送しません。確認終了後も確認用のモデル動画は保存可能です。素材URIが不明なアップロード処理を、同じ文章だけで別の結果へ復旧することは認めません。

ローカル処理は同時に1件、処理期限は各動画ツール3分／HTTP全体4分、接続元400MiB・AI部分200MiB・入力合計600MiB、接続後の全体400MiBまでです。失敗時は元ファイルを保ったまま説明を表示します。別タブとの素材・ジョブ共有、ローカル動画の永続ライブラリ、公開サーバーでの処理はありません。

## 画角・動画の解像度

**現在は横16:9・縦9:16のみを扱います。** 先に追加した正方形の試験的選択肢は、セミナーで使う構成を絞るため撤去しました。生成・動画取り込みとも1:1は選べません。API拒否時に自動再送や別画角への変更をせず、既存の動画は残します。

すべての画角で返却動画の幅と高さを検証します。予定の長さが合っていても画角が違う場合や実寸を確認できない場合は、完成版に採用せず確認用の動画・ジョブを保持します。再計測はローカルのみで、有料生成を再送しません。画角不一致でも生成した利用分の料金が発生する可能性があります。

最初の生成前に、画角は横16:9／縦9:16、動画解像度は360p／720p／1080p／4Kを選べます。新しく始める動画の既定は横16:9・360pです。延長・分岐は親の解像度を維持し、以前の720p動画も720pとして扱います。1080pと4Kはアップスケール出力であり、画像生成の解像度とは別です。2Kなど、動画解像度で対応を確認できない値は含めません。

文章からの初回生成では選択値を `response_format.aspect_ratio` / `resolution` に送信します。通常の延長では親の画角を指定し、アップロード延長ではaspect_ratioを省略します。送信時点の設定をジョブと各完成版に保持し、結果待ちや再取得でも変えません。このアプリでは物語の画角・解像度をそろえるため、延長や過去の版からの分岐も親動画の設定を引き継ぎます。変更したい場合は必要な動画を保存し「新しく始める」を選びます。これはアプリの方針です。Google APIが同条件を必須としている、または途中変更を保証するという明示は確認できていません。プレビューの「要求設定」は要求した条件です。「実寸」は動画メタデータの幅×高さで、返却されたAI出力と保存する動画を区別して表示します。旧版など未計測の場合はその旨を表示します。

Google公式ガイドは4種類の動画解像度を記載し、公式スクリプトは解像度を指定したmulti-turn延長を扱っています。公式スキルにも4K・30秒→40秒の延長例があります。高解像度は時間がかかるため、POST待機上限を通常10分、4K15分にしています。タイムアウトでも自動再送せず結果不明状態を保持します。実際の待ち時間・延長結果は未検証です。

Googleは360pを720pの約1/3の生成コストと案内しています。1080p／4Kを含む総請求額は断定せず、入力・出力・延長の利用量とGoogle公式の最新条件をご確認ください。

既に開いているタブは自動更新しません。新しいタブでURLを開けば新しい既定値を使えます。既存タブを再読み込みする場合は、メモリ内の動画・キーが消えるため必要な動画と診断を先に保存してください。動画アップロード機能を追加する前からサーバーを起動している場合、保存と処理完了の確認後に停止.command→起動.commandでサーバーを更新する必要があります。画面だけの再読み込みでは古いサーバーに動画処理APIは追加されません。

## 通信が途切れた場合

二重クリックは、同じタブの処理ロックで1回の送信に制限します。生成のPOSTリクエストを自動再送することはありません。

結果が不明な場合は、新しい生成を止め、「同じ結果を再取得（新規生成なし）」で**同じ生成IDのGET取得だけ**を行います。受信済み動画がある場合は「保存済み動画を再計測・仕上げ」でローカルの計測・接続だけを行えます。生成IDを受け取る前に切れた場合は、Google AI Studioのログで該当処理を確認し、その生成IDを入力します。既存版のIDや、プロンプト・延長元が違うIDは受け付けません。Googleの応答から一致を確認できない場合も、成功扱いにはしません。

尺不一致や計測不能でも生成IDと受信済み動画を保持し、新規生成をロックします。確認用動画は試行ごとに再生・保存でき、同じID・同じ内容の再取得は重複保持しません。再計測で採用された場合は表示も更新します。

「確認を終了し、新規生成を選ぶ…」はGoogle側の生成取り消し・返金ではありません。操作時の確認後もその場で生成は送信せず、生成ボタンを改めて押した場合だけ別のPOSTを送ります。確認用動画はセッション内に残ります。先の処理を確認し、追加課金の可能性を理解したときだけ選んでください。別タブや再読み込みをまたぐ重複生成を防ぐ仕組みはありません。

## 延長対象と結果の照合

公式資料の `[# Sources <PREVIOUS_VIDEO>@Video1]` 構文で前ターンの動画を延長対象にし、APIへ要求する追加3〜10秒と累計予定秒数をプロンプトへ明記します。`previous_interaction_id` も同じ親から設定します。`task:"extend"` と前の生成IDの併用について、公式サンプルではtaskを省略しているため、未確認の組み合わせを推測で追加していません。延長指示の改善が実生成で有効かは未検証です。

RESTの最新user_input以降を末尾から検索し、公式SDKと同じ規則で最後の動画を選びます。最新動画にデータがなければ古い候補へ戻らず、同じ結果の確認を続けます。応答の生成IDと親IDを照合し、延長元が応答にない場合は同じIDをGETで再確認します。それでも確認できない場合は完成版に加えません。手動ID復旧は入力も照合します。

## HTTP 400の切り分け

版2026-10-15.10では、Googleのエラーコードと確認できた対象項目を固定文で表示します。自由文のエラー本文は画面・診断・ログへ残しません。本文取得は16KiB・1.5秒で制限します。400だけでは入力不備と利用前提条件を区別できず、以前の失敗原因は未特定です。送信形式の監査は[docs/request-audit.md](docs/request-audit.md)に記録しました。仕様との明白な不一致が見つからなかったため、生成パラメータは変更していません。実APIの成功は未確認です。ご本人が手動で生成した後、表示されたコードまたは診断情報で切り分けます。

## 診断情報を手元に保存する

「診断情報を保存」からJSONをダウンロードできます。アプリ版、試行番号、POST/GET回数、HTTPステータス、処理状態、動画候補数と選択位置、各照合の判定、受信バイト数、実尺と判定に加え、送信予定の固定設定と安全なAPIエラー種別・対象項目だけを許可リスト方式で出力します。APIキー・認証ヘッダー・プロンプト・生成ID・URL・動画本文・APIの生レスポンスは含みません。外部送信や永続ストレージへの自動保存はありません。

タブを閉じる前に、必要な確認用動画と診断JSONを保存してください。診断JSONだけでは生成IDを復元できず、再読み込み後の処理再開用ファイルではありません。

## 料金と仕様上の限界

実生成は無料ではなく、利用者ご本人のGoogle API課金です。採用しなかった生成物も、生成済みの利用量は課金対象です。失敗・拒否・通信切断時の画面だけでは請求の有無を判定できません。Google側の使用量と請求を確認してください。入力・出力トークンによる料金のため、動画の秒単価だけから40秒完成までの総額を確約しません。

初回・延長とも希望の長さは3〜10秒（既定10秒）です。Google公式スクリプトが検証する整数範囲に合わせ、APIへは `response_format.duration: "3s"`〜`"10s"` を送ります。延長では追加分であり、累計尺ではありません。1・2秒を生成後に切り詰める方式は廃止しました。

上限付近の次の延長でモデル部分が40秒を超える場合は、現在の完成版の末尾10秒以下を新しくアップロードするため、元が文章生成でも持ち込み動画の地域制限（EEA・スイス・英国では非対応）と新しいセリフ追加の制限が適用されます。

指定した秒数どおりの厳密な実尺は保証されません。予定尺・加工前の実尺・採用したAI部分の実尺・保存する全体の実尺を分けて扱います。モデル部分の予定との差は0.1秒以内を採用条件とし、実尺40秒超は自動受理しません。文章から始めた全体も厳密に40秒以下です。ローカル接続後も0.1秒以内の整合を検証します。上限超過を黙って切って成功扱いしません。計測・接続に失敗した結果はジョブと元出力を保持し、APIへ再送せずローカルで再確認できます。修正後の実API生成・尺の精度・連続性・実請求は未検証です。

延長は末尾の最大10秒を参照し、つながりのために末尾の一部フレームを調整します。各版は独立して残ります。Vids内部処理の完全再現や無限延長を提供するものではありません。日本語の生成品質、モデルの利用地域・利用枠、実際の長さ・映像の連続性・請求額は、修正後の実API生成で未確認です。
